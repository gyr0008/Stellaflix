## A. 入口与导航

1. **三卡进三轴**：首页「歌单 / 专辑 / 艺人」三张卡各点对应轴，首帧即生效（不用先刷新）。
2. **两级退出（按轴两形态，批D 改）**：
   - 专辑/歌单＝居中弹窗：ESC／底栏「关闭」钮／点弹窗外遮罩空白处任一 → 关弹窗回网格；再 ESC 关整库。
   - 艺人＝全屏 hero 页：左上 999px 胶囊返回钮与 ESC 等价 → 回网格；再 ESC 关资料库。
3. **ESC 不越界**：资料库没打开时按 ESC，不得干扰其它页面原有的 ESC 行为。
4. **滚动往返（仅艺人全屏轴有）**：艺人轴网格滚到中段→进全屏详情（从顶部开始）→返回（应恢复网格原来那一屏，不跳顶）。专辑/歌单弹窗每次开窗把**弹窗内**滚动置顶，不回写、不干扰底下的网格滚动位置。
5. **影视态闸**：切到影视态后点这三张卡，资料库不得起来；回到音乐态恢复可点。

## A2. 详情两形态（10-26 批D 新增/重写，代码证不了、交主人真机验）

A2-1. **专辑点开＝居中弹窗**：点专辑卡出现的是**居中主题弹窗**（不是铺满整屏的页面）；封面的取色渐变主色铺满面板可见（无封面的深色兜底也自然）；底栏「关闭」钮可见可点；点弹窗外的遮罩空白处能关；按 ESC 能关；切到别的轴再切回来**不残留**上一张专辑的内容；关整库时弹窗**当场收干净**，遮罩不浮在首页上；**专辑轴随机钮不出现**（只有「播放专辑」一颗整单钮）。
A2-2. **歌单点开＝弹窗带随机**：同弹窗形态，但播放钮旁多一颗**浅色玻璃随机圆钮**（`.stella-mlib-shuffle-btn`）可见可点；随机走「打乱后播这批第一个」。(注：引擎侧 `getPlaylists` 恒空 ⇒ 歌单轴目前只能验证弹窗**空态**，带真曲目的随机手感待引擎接上后复验。)
A2-3. **艺人点开＝全屏 hero 页（非弹窗）**：点艺人卡仍是**铺满整屏的二级页**——大圆形头像/首字母兜底 + eyebrow + 页标题 + head-meta + 曲目列表；左上 999px 胶囊返回钮；返回时网格滚动位置恢复（见 A4）；艺人轴不吃 `entity.cover`。
A2-4. **艺人轴关库当场复位（批D 收口新增）**：在艺人全屏详情下关整库时，`mlib-detail-open` 现在 **0ms 就摘**（不再等 260ms 页面离场动画）——真机看一眼这一档离开时的画面：详情内容不应「闪一下还挂在半透明层上」或撕裂，离场观感不突兀即通过。
A2-5. **简介块（有 description 才验）**：目前引擎不产 `entity.description`，专辑/歌单弹窗默认**无简介块**属正常（不占位、不合成，见 spec §4）；若缝给了，默认折叠三行 + 「展开简介」钮可展/收。

## B. 数据与状态

6. **引擎未挂载的空态**（曲库引擎由并行会话负责，此刻可能还没接上）：三轴各自出现「曲库引擎尚未就绪 / 导入歌单或本地音乐后这里会自动出现」一类状态盒，**不白屏、不报错、不转圈**；盒里「去导入」点开导入框，「重试」真的重新发一次读请求。
7. **详情状态（两形态共通）**：详情读到错误时，标题/信息区照常显示、列表区出现状态盒且错误文案是缝原话（不被吞成「读取失败」）。弹窗轴状态盒在信息区下方（`#mlib-detail-modal-status`），error／空轨／无可播轨时整单播放钮与随机钮一律 disabled（点了不响是设计，不是 bug）。
8. **未匹配曲目**：`matched:false` 的行照常显示与计入曲数，单曲播放钮置灰且 title=「未匹配到可播来源」；点整张（专辑/歌单）时这些行被跳过。

## C. 观感与手势

9. **壁纸/mask/播放器条**：透明压在壁纸上时的观感、上下 mask 渐隐、底部播放器条不被内容压住；悬停动画只位移不缩放；圆形播放钮是毛玻璃且不遮封面关键内容。
10. **无 hover 设备分支**：把鼠标彻底移开（或触屏）时圆形钮隐藏，整张封面即点即播；艺人头像点的是详情，不是即播。

## D. 播放链口径（真曲库到位后才可测）

- 点整张/单曲＝**追加**后立刻播「这一批的第一个新条目」：既有的队列不被清空、不被替换。
- 本地有文件的曲目走本地优先，联网匹配只用于切音质。
