# 汇联 BT 磁力播放 — 真机冒烟清单（Task8 交付）

> 适用：Windows 桌面版（`npm start` 或打包后的 Stellaflix exe），非浏览器 :3000。
> 前置：已配置 qBittorrent（WebUI 端口默认 8080）与 mpv（`mpv-1.dll` 就位）；
> 每条按「操作 → 预期」执行并打勾。任何一条不符即视为回归，记录现场截图 + `%APPDATA%\Stellaflix` 下相关日志。

## 0. D3 凭据轮换 + CSRF 会话（首要——本地无法自动化验证的部分）

qbt 4.6.1+ 默认开启 CSRF 防护；D3 首启会把 WebUI 口令轮换为随机 32 位十六进制，此后所有
非 GET 调用（加任务/删除/暂停等）依赖复放 cookie jar（SID + qbt_response_sid）并携带
`X-CSRF-Token`。测试从未对真实 qbt 发起过这些调用，本条必须真机确认。

- [ ] 0.1 首启轮换：删除（或首次生成）`%APPDATA%\Stellaflix\huilian-qbt-cred.json` → 启动桌面版 → 进汇联页加一次磁力触发 qbt 启动。
  预期：凭据文件生成，内容 `{username, password}` 且 password 为 32 位十六进制随机串；文件不存在 `.tmp.*` 残片。
- [ ] 0.2 口令生效：用 qbt 网页控制台手动以旧默认口令登录 → 应失败；用凭据文件里的新口令登录 → 成功。
  （确认轮换真实落到了 qbt，而不是只写了本地文件。）
- [ ] 0.3 CSRF 复放：qbt 版本 ≥4.6.1 时，在汇联页依次执行 加任务（磁力）、加任务（.torrent）、暂停（若有 UI）、删除任务。
  预期：全部成功、页面无红色错误条；qbt 侧对应任务确实出现/消失。若见 `403 Forbidden`/「加入任务失败」类提示 → 即本清单存在的意义，记录 qbt 版本。
- [ ] 0.4 重启复用：杀掉 Stellaflix 与 qbt 后全部重启（凭据文件已存在，走 stored 分支零 HTTP）→ 再次加/删任务。
  预期：会话重登成功（旧 SID 作废后重新 login），非 GET 调用依旧全部放行。
- [ ] 0.5 安全红线：以上任何环节的日志、错误条、控制台输出中不得出现明文口令。

## 1. 磁力加入 → 认领 → 进度

- [ ] 1.1 粘贴合法 `magnet:?xt=urn:btih:...` → 点「加入下载」→ 列表先出现灰色虚化「新任务（等待元数据）」行（解析中）。
- [ ] 1.2 元数据就绪后 ≤2s（轮询周期）该行消失，出现带任务名的真实任务行：`名称 · 下载中 · xx% · ↓速度 ↑速度`。
- [ ] 1.3 无效输入（空/非 magnet 且未选文件）→ 输入下方出现红色错误条中文提示，不发起 IPC。

## 2. .torrent 本地文件上传（D2 multipart base64）

- [ ] 2.1 点「浏览…」→ 出现系统文件选择框（页面内不应看见裸 file input）→ 选一个本地 `.torrent`。
- [ ] 2.2 任务直接入列（≤2s 出现任务行），qbt 侧同名种子存在。
- [ ] 2.3 再选同一文件 → 仍能触发 change（选择框已复位），不弹错。

## 3. 文件展开与可播阈值

- [ ] 3.1 点任务行 → 展开文件子行（`名称 · 百分比`），再点 → 折叠。
- [ ] 3.2 进度 ≥ 阈值的文件行高亮可点（鼠标手型 + hover 背景）；不足阈值的行灰显、点击无动作且**不折叠**文件列表。
- [ ] 3.3 展开后等一轮 2s 轮询重绘 → 展开态保持、内容不被清空。

## 4. 点击播放 + overlay 跟位（D1 桌面数学，无真窗测覆盖）

- [ ] 4.1 点可播文件行 → 黑底视频容器被原生 mpv 画面精确覆盖（位置/尺寸零偏差），页面出现控件条。
- [ ] 4.2 拖动主窗口 → 画面跟随容器，无残影、不遮导航栏（#sfv-nav）。
- [ ] 4.3 拖拽改变窗口尺寸 / 最大化 / 还原 → 画面持续贴合容器矩形（≤500ms 内到位）。
- [ ] 4.4 页面内容滚动（任务列表变长后滚轮下滑）→ 画面跟位不错位。
- [ ] 4.5 DPI 缩放：Windows 显示缩放 150% 与 233% 各试一次 4.1–4.4 → 位置/尺寸仍精确（zoom 换算验证）。
- [ ] 4.6 控件条：暂停↔继续（按钮文案切换、画面确实暂停）、拖动进度条松手后跳转、音量滑条即时生效、「仅关闭」→ 画面消失任务保留。
- [ ] 4.7 播放中点另一个可播文件 → 旧画面先销毁再开新画面（任一时刻至多一个 overlay，无叠窗/残窗）。

## 5. 播完面板（边播边删）

- [ ] 5.1 自然播完（或 seek 到片尾）触发 end-file → 控件条下方出现「已播完」面板：删任务+删文件 / 保留任务。
- [ ] 5.2 点「删任务+删文件」→ 画面与控件条消失；qbt 中任务消失；磁盘上下载文件被清理。
- [ ] 5.3 重复快速连点删除按钮 → 停止/删除各只发生一次（无二次报错）。
- [ ] 5.4 若 mpv 播放中途进程被外部杀掉（任务管理器）→ 出现「播放已中断」降级面板，「重试」能重建画面。

## 6. 路由生命周期红线（unmount / 返回）

- [ ] 6.1 播放中切到首页/片库/世界任意 tab → **画面立即消失**，无残留悬浮窗（黑块/最后一帧都不允许）。
- [ ] 6.2 切走时 qbt 任务不受影响（仍在下载），且**未**弹出任何删除确认。
- [ ] 6.3 切回汇联页 → 任务列表恢复轮询并正确重绘；先前展开/播放状态不残留旧代（无幽灵控件条）。
- [ ] 6.4 播放中直接退出应用 → 无孤儿 mpv 进程、qbt 由应用的清理路径处理。

## 7. 非桌面降级

- [ ] 7.1 浏览器直开 `http://localhost:3000` → 进汇联 tab：出现金色提示条「BT 播放需在 Stellaflix 桌面版中使用」，输入框/按钮置灰不可点，无 JS 报错刷屏。
